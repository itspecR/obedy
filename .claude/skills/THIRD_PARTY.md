# Сторонние скиллы

Источник: https://github.com/emilkowalski/skills, коммит `2d228630ba1446365f614a108cb8252f1feda202` (11.10.2026). Лицензия MIT, текст в `LICENSE-emilkowalski-skills`.

Установлены без изменений: emil-design-eng, animate, review-animations, improve-animations, find-animation-opportunities, animation-performance, animation-vocabulary, apple-design, mobile-native, break-ui, prototype.

Не установлены, потому что не подходят к стеку проекта (Vue и обычный CSS): animate-expo, write-swift, ask-sonner, pick-ui-library.

Правила проекта важнее советов из скиллов:

- в рабочем коде нет комментариев, даже если пример в скилле их содержит;
- новые зависимости, в том числе Motion и framer-motion, добавляются только после решения владельца;
- анимации пишутся на CSS и Web Animations API, уже принятых в проекте.
